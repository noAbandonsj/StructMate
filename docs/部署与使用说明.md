# 本地部署与学习流程

更新：2026-10-20。面向桌面网页，单机、单个后端 worker；SQLite、Qdrant 本地目录和文件均保存在配置的数据目录。DeepSeek 与千问 HTTP 适配已完成，真实学习闭环及针对性内容回归已完成，见 [验收记录](真实模型闭环验收记录.md)。

## 安装和准备数据

按 [README](../README.md) 安装锁定的 Python 与前端依赖，复制 .env.example 为根目录 .env（已有文件保留），执行迁移和课程目录初始化。系统不自带学习资料、题库或推荐外链，课程资料由管理员在网页上传维护。维护命令不会创建演示账号。

已有数据库先备份再执行 `alembic upgrade head`。当前为 0001–0014、17 个业务实体；不执行历史设计 SQL。0013 清空旧对话、题目、练习、作答、错题和报告，保留账号、知识库、上传资料、文档任务和管理员维护资源，并将分类统一为平面章节模型。0013 没有历史读取兼容，降级也会清空学习记录；恢复数据需还原升级前完整备份。0014 仅移除消息回答方式字段及约束、更新原提问请求摘要，保留现有消息与引用；降级统一恢复默认讲解值，不还原旧模式。迁移后校验外键及模型差异，不需要重建向量。

## 两种本地启动方式

开发页面时，分别运行 scripts/start-backend.ps1 和 scripts/start-frontend.ps1，访问 http://127.0.0.1:5173；Vite 将 /api 代理到后端 8000。后端可加 -Reload。

使用构建版本时，在仓库根目录运行：

```powershell
Push-Location frontend
pnpm.cmd build
Pop-Location
.\scripts\start-backend.ps1 -ServeWeb
```

访问 http://127.0.0.1:8000；网页、带指纹的 JS/CSS 和 /api 来自同一个进程和地址，不需要 Vite 常驻。-ServeWeb 只在本次脚本运行时启用对应配置，结束后恢复原进程环境；也可在 .env 设置 CAPSTONE_SERVE_FRONTEND=true。缺少构建文件时明确停止启动并提示先构建。更新前端后重新构建，刷新网页使用新入口。

聊天、练习、报告等带 ID 的网页路径刷新后仍返回页面入口；不存在的 API 和静态资源保持 404，不回退为网页。后台服务同样检查所有私有对象权限，不能凭网页路径获取他人记录。接口文档为 /docs，健康接口为 /api/v1/health。

默认只监听本机 127.0.0.1，一个 worker。不要同时用多个后端进程打开同一个 Qdrant 目录。终端 Ctrl+C 停止服务。若日后部署到对外地址，production 模式的 Cookie 需要 HTTPS；反向代理应保留 Host 和协议，并允许 SSE 流式传输、不缓存 API。当前交付支持站点根路径，不配置子路径部署或外网发布。

## 实际操作顺序

1. 在登录页创建账号，注册后直接进入首页；已有账号可登录。刷新恢复有效会话，右上角可修改显示名称和退出。
2. 生成模型配置就绪后，可以先使用实时 AI 练习。课程目录提供八章，课程资料等待管理员上传维护；上传个人资料是可选路径。
3. 在“我的知识库”选择个人库，上传文本型 PDF、TXT 或 Markdown，选填章节。可预览、下载、删除和重试；课程库只读并展示来源。未配置 Embedding 时文件保留但不会假装就绪，扫描 PDF 不提供 OCR。
4. 真实模型接通且资料就绪后，“学习对话”默认使用课程资料＋我的学习资料，不提供范围选择；从某份资料进入时保留该资料限定。列表只显示未归档会话，每项旁的铅笔图标可改名，收纳盒图标可归档；归档当前会话后返回列表，操作其他会话不切换当前对话。旧链接仍可查看已归档会话，并通过列表中的恢复图标恢复。可提问、追问、查看引用，直接在问题中要求提示或举例；支持取消生成、失败重试和刷新恢复；引用或会话可带章节进入练习。
5. “练习中心”统一实时 AI 出题。选择一个内置章节，可选填写练习要求、选择最多 5 份就绪参考资料，默认基础难度、5 题；系统记住上次章节。资料限所选章节及未分类资料，从已分类资料进入会自动选择章节。没有参考资料时依据 AI 通用知识出题。生成后独立复核参考答案，失败保留设置并允许重试，不回退题库。
6. 按需查看提示，完成本组全部有效题目后点击“提交全部答案”，统一显示判题、解析和来源；提交前可修改选择，网络失败保留草稿，重复提交不重复计分。AI 按保存的参考答案判题。错误自动进入“错题本”，支持章节筛选、题目搜索、状态筛选、原题或成组复习及历次记录；不同上海日期连续两次答对标记该题已巩固，再答错回到待复习。
7. 会话下方可按需总结已完成问答并导出，范围和截止时间固定，新消息不混入已开始生成的总结。生成失败保留上次成功内容；实际总结仍需生成模型。
8. “学习报告”默认查看最近 7 个上海日期，也可选择范围。实时数字不依赖模型；保存时固定历史快照，文字报告需模型，未接通仍可保存和导出真实数字，明确文字尚未生成。后续作答或题目停用不改写旧报告。
9. 首页、会话和报告可阅读推荐资料，查看章节、有效错题和难度的匹配理由；本地原文再次检查权限和就绪状态，外链为维护者登记的真实资源，不依赖模型编造链接。

首次独立新题、提示、重复和复习分开统计；少于 5 道独立新题仅说明证据不足。空记录显示空状态，正确率没有分母时显示未评估，不估算学习时长。输入草稿按账号隔离，退出清理，只有服务端已提交记录参与统计。

## 模型与评估

管理员通过相同登录页进入，在侧栏“课程资料管理”维护课程文件。注册不接受角色字段，首次授权、查询及撤销只通过本机 `capstone.manage_admin` 命令完成，不自动设置管理员，不提供默认密码。课程写接口每次检查当前角色和课程归属，管理员也不能访问他人的私人资料。完整步骤见 [课程维护说明](管理员课程资料维护说明.md)。

连接参数见 [模型接入说明](模型接入说明.md)。普通用户界面不展示密钥、向量维度或内部任务编号。实际 .env 只在后端使用，不复制到 frontend，不加入 Git。已确定 DeepSeek 生成与千问 Embedding 的兼容接口；示例密钥留空，填写地址、模型与密钥并重启后才启用调用；当前本地配置已完成真实验收。

真实服务接通后，先重试课程资料并确认向量就绪，再按 [RAG评估说明](RAG评估说明.md) 运行开发集和独立保留集，核对实际答案与原文支持；同时经真实业务接口完成 AI 练习、总结和报告。测试替身结果不能替代真实验收。

模型接通不会自动重放之前失败的课程任务。管理员在“课程资料管理”页面检查失败原因并点击重试，确认资料显示“可用于学习”，再验证仅课程范围的一轮真实答疑。健康接口正常只说明存储可用，不代表模型可调用或课程已就绪。

首页显示课程与个人就绪资料数量，未就绪时给出上传、实时 AI 练习等入口；课程失败由维护者处理，学生页面显示上次失败时间。当前会话范围没有就绪资料时，发送前提示并保留草稿，服务端也拒绝新增问题。资料就绪后点击“重新检查资料”即可恢复。

新统计中的“有效答疑”不含检索未命中的固定资料不足回复，后者单独显示；新总结排除这类问答。旧报告仍显示生成时数据，并标明“完成回复（旧口径）”可能包含资料不足，重新生成才使用新统计。资料不足不代表模型已成功讲解，也不能据此推断掌握情况。

## 数据备份与恢复

停止后端后，备份完整数据目录以及单独保管的 .env；资料文件、SQLite 和 Qdrant 应使用同一份完整备份。不要只恢复 SQLite 后继续使用不同时间的向量目录。可先将备份恢复到新目录，再调整 CAPSTONE_DATA_DIR 指向该目录并启动核对，保留原目录以便回退。升级前的 SQLite 快照位于 data/backups/，不替代完整文件与向量备份。

本版不提供教师端、验证码、找回密码、手机适配、Docker、Redis、Celery、通用任务平台或浏览器自动检查。
