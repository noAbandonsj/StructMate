# 本地部署与学习流程

更新：2026-10-16。面向桌面网页，单机、单个后端 worker；SQLite、Qdrant 本地目录和文件均保存在配置的数据目录。DeepSeek 与千问 HTTP 适配已完成，真实学习闭环及针对性内容回归已完成，见 [验收记录](真实模型闭环验收记录.md)。

## 安装和准备数据

按 [README](../README.md) 安装锁定的 Python 与前端依赖，复制 .env.example 为根目录 .env（已有文件保留），执行迁移、目录初始化、课程导入、题库及资源导入。这些维护命令不会创建演示账号，重复运行不会重复新增相同内容。

已有数据库先备份再升级，使用 `alembic upgrade head`，不执行历史 docs/design/schema.sql。当前为 0001–0007、16 个业务实体。不要在真实数据上做测试降级。

## 两种本地启动方式

开发页面时，分别运行 scripts/start-backend.ps1 和 scripts/start-frontend.ps1，访问 http://127.0.0.1:5173；Vite 将 /api 代理到后端 8000。后端可加 -Reload。

使用构建版本时，在仓库根目录运行：

```powershell
Push-Location frontend
pnpm.cmd build
Pop-Location
.\scripts\start-backend.ps1 -ServeWeb
```

访问 http://127.0.0.1:8000；网页、带指纹的 JS/CSS 和 /api 来自同一个进程和地址，不需要 Vite 常驻。-ServeWeb 只在本次脚本运行时启用对应配置，结束后恢复原进程环境；也可在 .env 设置 CAPSTONE_SERVE_FRONTEND=true。缺少构建文件时明确停止启动并提示先构建。更新前端后重新构建，刷新网页使用新入口。

聊天、练习、报告等带 ID 的网页路径刷新后仍返回页面入口；不存在的 API 和静态资源保持 404，不回退为网页。后台服务同样检查所有私有对象权限，不能凭网页路径获取他人记录。接口文档为 /docs，健康接口为 /api/v1/health。

默认只监听本机 127.0.0.1，一个 worker。不要同时用多个后端进程打开同一个 Qdrant 目录。终端 Ctrl+C 停止服务。若日后部署到对外地址，production 模式的 Cookie 需要 HTTPS；反向代理应保留 Host 和协议，并允许 SSE 流式传输、不缓存 API。当前交付支持站点根路径，不配置子路径部署或外网发布。

## 实际操作顺序

1. 在登录页创建账号，注册后直接进入首页；已有账号可登录。刷新恢复有效会话，右上角可修改显示名称和退出。
2. 可以先做题库练习。课程目录提供八章，首批内容覆盖线性表、栈与队列、二叉树；上传个人资料是可选路径。
3. 在“我的知识库”选择个人库，上传文本型 PDF、TXT 或 Markdown，选填知识点。可预览、下载、删除和重试；课程库只读并展示来源。未配置 Embedding 时文件保留但不会假装就绪，扫描 PDF 不提供 OCR。
4. 真实模型接通且资料就绪后，在“学习对话”选择课程、个人或合并范围，提问或继续追问，点击引用查看原文位置。可选择提示或例子，取消生成、失败重试、刷新恢复；引用或会话可带知识点进入练习。
5. “练习中心”切换题库或实时 AI，两种模式保留知识点、题量和难度，只影响新练习。默认 5 题、基础难度；题库不足明确显示实际数量。AI 支持额外自然语言要求，不限于程序可验算题；当前调用未接通时明确失败，不自动切换题库。
6. 按需取提示后提交，页面显示判题、解析和来源；重复提交不重复计分。AI 按保存的参考答案反馈，有误可反馈给维护者。错误自动进入“错题本”，支持筛选、原题或成组复习及历次记录；不同上海日期连续两次答对标记该题已巩固，再答错回到待复习。
7. 会话下方可按需总结已完成问答并导出，范围和截止时间固定，新消息不混入已开始生成的总结。生成失败保留上次成功内容；实际总结仍需生成模型。
8. “学习报告”默认查看最近 7 个上海日期，也可选择范围。实时数字不依赖模型；保存时固定历史快照，文字报告需模型，未接通仍可保存和导出真实数字，明确文字尚未生成。后续作答或题目停用不改写旧报告。
9. 首页、会话和报告可阅读推荐资料，查看知识点、有效错题和难度的匹配理由；本地原文再次检查权限和就绪状态，外链为维护者登记的真实资源，不依赖模型编造链接。

首次独立新题、提示、重复和复习分开统计；少于 5 道独立新题仅说明证据不足。空记录显示空状态，正确率没有分母时显示未评估，不估算学习时长。输入草稿按账号隔离，退出清理，只有服务端已提交记录参与统计。

## 模型与评估

连接参数见 [模型接入说明](模型接入说明.md)。普通用户界面不展示密钥、向量维度或内部任务编号。实际 .env 只在后端使用，不复制到 frontend，不加入 Git。已确定 DeepSeek 生成与千问 Embedding 的兼容接口；示例密钥留空，填写地址、模型与密钥并重启后才启用调用；当前本地配置已完成真实验收。

真实服务接通后，先重试课程资料并确认向量就绪，再按 [RAG评估说明](RAG评估说明.md) 运行开发集和独立保留集，核对实际答案与原文支持；同时经真实业务接口完成 AI 练习、总结和报告。测试替身结果不能替代真实验收。

## 数据备份与恢复

停止后端后，备份完整数据目录以及单独保管的 .env；资料文件、SQLite 和 Qdrant 应使用同一份完整备份。不要只恢复 SQLite 后继续使用不同时间的向量目录。可先将备份恢复到新目录，再调整 CAPSTONE_DATA_DIR 指向该目录并启动核对，保留原目录以便回退。升级前的 SQLite 快照位于 data/backups/，不替代完整文件与向量备份。
