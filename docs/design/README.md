## 历史对照

- archive/v0.1/ 保存自检前的规划、页面、数据和接口文档。
- schema.sql、verify_design.py、qa/schema-checks.json 属于原始 v0.1，可作为约束验证的历史参考。
- verify_wireframe.cjs 与 qa/ 中截图和交互结果属于旧线框的历史检查，不作为当前开发依赖或验收门槛。
- 原型中已有的手机样式仅属于历史展示，本版不扩展、检查或维护手机适配。

规划自检未启动浏览器或修改可点击原型。随后工程初始化进行了基础存储测试、迁移与构建检查以及 HTTP 连通验证；没有进行浏览器检查。浏览器自动检查暂不开发；业务实现阶段仍需要权限、判题与统计验证。

## 首个实施目标

账户阶段的目标：注册自动登录并建个人库 → 查看个人库、只读课程库和固定目录 → 刷新保持登录 → 退出。批次 A–D 已完成；课程库建成不代表课程文档已入库。

随后：导入课程资料或上传个人文件 → 资料就绪 → 自然语言提问 → 查看真实引用。再接入题库 / 实时 AI 可切换的知识点练习、自动错题、总结、报告和推荐。

六个页面保留，平台型管理功能延期。默认设置先让学生开始学习，高级选项逐步展开。
