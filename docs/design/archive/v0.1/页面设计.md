# 页面与交互设计 v0.1

日期：2026-10-10。状态：可点击线框与页面契约，尚未接入真实后端。

## 1. 页面组织

采用六个主要页面，顶部显示当前页面和学习范围，桌面左侧固定导航区域，窄屏转换为顶部导航。资料推荐嵌入首页、对话和报告；对话总结放在对话内，避免增加独立导航层级。

| 页面 | 建议前端路由 | 核心操作 |
| --- | --- | --- |
| 登录 / 注册 | `/login`、`/register` | 登录、创建账户；正式开发加入，线框默认已登录 |
| 学习首页 | `/` | 继续会话、开始基础练习、查看待复习内容 |
| 我的知识库 | `/knowledge`、`/knowledge/:kbId` | 创建个人库、上传、预览片段、查看任务、重试与删除 |
| 学习对话 | `/chat`、`/chat/:conversationId` | 选择知识库、提问、取消或重试、展开依据、总结、进入练习 |
| 练习中心 | `/practice`、`/practice/:sessionId` | 选择知识点、生成练习、答题、提示、查看解析和反馈 |
| 错题本 | `/wrong`、`/wrong/:wrongId` | 知识点筛选、查看错误历史、创建复习练习 |
| 学习报告 | `/reports`、`/reports/:reportId` | 选择日期范围、查看统计、生成报告、导出与查看推荐 |

“知序”是线框中的暂定名称，不代表最终产品命名。前端实现暂按 Vue 3 + TypeScript 组织，界面结构不依赖该框架。

## 2. 学习对话线框

```text
┌ 导航 ──────┬ 学习对话 / 当前会话 ───────────────────────┐
│ 学习首页   │ 范围：个人库 / 课程资料     教学方式         │
│ 我的知识库 ├───────────────────────┬───────────────────┤
│ 学习对话   │ 用户问题               │ 引用资料          │
│ 练习中心   │ 回答正文与代码示例      │ 标题、版本、定位  │
│ 错题本     │ [1] 引用入口            │ 对应证据摘录      │
│ 学习报告   │ 练习此知识点 / 总结     │ 原文预览          │
│            ├───────────────────────┤                   │
│            │ 提问输入框 / 发送      │                   │
└────────────┴───────────────────────┴───────────────────┘
```

回答优先占用主要空间，引用可展开。引导思考模式先显示提示和追问，直接讲解模式展开定义、例子及算法分析。输入框支持换行，发送行为明确；生成中展示取消操作和状态，避免同会话重复发送。

引用点击后显示真实来源，不把资料名称当作可靠性评分。原文已删除时显示来源状态，隐藏摘录；没有检索证据时明确说明，不显示虚构引用。

完整实现需要会话列表和新建会话入口，线框优先展示一段典型会话及其学习动作。用户切换知识库范围只影响后续回答，历史引用保留原版本。

## 3. 知识库线框

```text
我的知识库                            创建知识库
├ 课程资料（只读）
│  资料名 / 知识点 / 就绪状态 / 查看片段
└ 个人知识库                           上传资料
   资料名 / 当前版本 / 处理状态 / 操作
   └ 任务详情：解析 → 切分 → 向量化 → 就绪
```

课程资料与个人资料区分可见范围。上传前展示支持格式及大小，任务失败展示原因和重试入口；扫描件不误显示为可检索。

删除前展示具体文档名和影响，再确认删除；删除即停止新检索，后台清理状态可查询。重新处理时旧版本仍可用，新版本就绪后切换。

## 4. 练习与错题线框

```text
练习中心：章节 / 知识点 / 难度 / 题量
┌ 本题知识点 / 序号 ──────────────────────────┐
│ 题干                                       │
│ ○ A 选项                                   │
│ ○ B 选项                                   │
│ ○ C 选项                                   │
│ 提交答案                    给我一个提示   │
├ 提交后：结果 / 正确答案 / 解析 / 依据 ───────┤
│ 下一题 / 查看错题 / 题目有问题              │
└────────────────────────────────────────────┘

错题本：知识点 / 待复习 / 复习中 / 已巩固
题干摘要 / 错误次数 / 最近作答 / 复习日期
→ 查看历史 → 重做题目 → 更新复习状态
```

答案在提交后出现。获取提示立即记录提示使用；提交后锁定当前条目，重做创建新条目。AI 题目显示生成来源；问题反馈不立即改变判分，核实后撤销影响。

错题复习保留首次错误记录，正确一次不直接认定知识点已掌握。原题已撤销时清晰标注，并从有效学习统计排除。

## 5. 首页与报告线框

```text
首页
最近一次学习 → 继续对话 / 开始练习
有效作答数 | 首次正确率 | 待复习错题
下一步：基础测验 / 薄弱知识点 / 推荐片段

学习报告
日期范围 / 时区 / 生成报告 / 历史报告
统计事实 → 知识点练习记录 → 学习建议 → 推荐资料
数据截止时间 / 口径 / 过期提示 / 导出 Markdown
```

初次使用时提供课程资料入口和基础练习，不显示虚构掌握率。首页的待复习数只统计到期且有效的条目；报告同时区分首次作答和复习，展示证据数量。

没有可靠计时数据时不显示学习时长。个人资料片段和外部资源使用不同来源标签，外链只使用维护的实际地址。

## 6. 状态与交互约定

| 状态 | 页面反馈 | 恢复方式 |
| --- | --- | --- |
| 没有个人资料 | 显示上传入口及课程资料入口 | 上传或使用课程库 |
| 文档处理失败 | 失败阶段、可理解原因、任务状态 | 重试或更换文本资料 |
| 回答证据不足 | 说明资料范围不足 | 补充资料、改写问题 |
| 模型不可用 | 错误状态，不把部分回答当成完成 | 主动重试；仍可使用既有练习 |
| 会话正在生成 | 取消按钮、禁止同会话新发送 | 等待或取消 |
| 练习题量不足 | 显示实际题量和原因 | 减少题量或换章节 |
| 无作答记录 | null 正确率、未评估 | 基础测验 |
| 作答样本少 | 展示正确次数和证据不足 | 多做新题 |
| 报告已过期 | 保留原快照并标注 | 重新生成 |

交互使用原生输入与按钮，键盘可操作，错误状态有文字说明。桌面展示聊天与引用两列；窄屏改为上下布局，表单和操作按钮可换行，不缩小文字强行塞入。

## 7. 当前可点击范围

当前线框可以切换六个页面、查看引用、切换讲解方式、显示示例总结、完成三道示例题、收录错题、复习并更新模拟报告，还可模拟资料处理。它没有访问模型或后端，模拟上传不会读取或保存用户文件。

未在当前线框实现的内容包括注册登录、知识库创建与删除、真实文档解析、完整会话管理、日期筛选和导出；这些仍在首版功能范围内，按接口清单逐步接入。
