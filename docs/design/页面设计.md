# 桌面网页与交互设计 v0.3

更新：2026-10-15。已实现桌面导航、登录/注册、账户恢复与路由保护、账户菜单、知识库列表与详情及课程目录搜索；资料保存、列表、预览/下载、删除与失败重试已接入；学习对话页面已接入，练习与错题页面已接入；真实模型、会话总结已接入，报告及推荐待完成。本版面向桌面网页，不设计手机端导航或布局，不将浏览器自动检查纳入当前实施任务。

## 1. 页面与导航

保留学习首页、我的知识库、学习对话、练习中心、错题本、学习报告六个主要入口。使用左侧主导航、主要内容区和可展开的资料引用侧栏。总结与推荐就地出现，不增加独立管理页面。

桌面参考宽度为 1280–1920px；1024px 可作为较窄桌面窗口的参考，保持正常文字与操作区尺寸。无需 320px 布局、触屏手势、移动导航或手机截图验收。

| 页面 | 路由 | 核心动作 |
| --- | --- | --- |
| 登录 / 注册 | /login、/register | 注册自动登录并建个人库；已有用户登录；刷新恢复会话 |
| 学习首页 | / | 开始学习、继续会话、上传资料、基础练习 |
| 我的知识库 | /knowledge | 课程库与个人库、上传、状态、预览、删除、重试 |
| 学习对话 | /chat、/chat/:id | 会话列表、提问、引用、练习此知识点、最新总结 |
| 练习中心 | /practice、/practice/:id | 切换题库 / AI 出题、开始练习、答题、提示、解析、结果 |
| 错题本 | /wrong | 待复习、知识点筛选、历史作答、重做 |
| 学习报告 | /reports、/reports/:id | 实时统计、生成解释、历史报告、导出、推荐 |

“知序”是原型暂定名称；基础工程已采用 Vue 3 + TypeScript + Vite。

## 2. 首次使用

注册成功自动登录并进入首页，无须再次填写密码；若从本站学习页面进入登录，登录后返回原目标。恢复登录期间先显示加载状态，退出或换账号清除原用户缓存与草稿。顶部菜单提供修改显示名称和退出。

当前账户流程已落地，首页展示本人显示名称和默认个人库名称；我的知识库显示个人库与只读课程库，点击卡片读取详情，并支持目录展开与知识点搜索。页面分开处理知识库和目录的加载错误，退出或换账号清空旧数据，迟到响应不会覆盖新账号或新选择。资料页面提供上传与状态，未接通模型时明确提示可保存和预览、不能用于对话。首页仍显示学习功能准备状态。具体界面状态与验收见 [下一阶段实施规划](../下一阶段实施规划.md)。

账户表单仅要求用户名和密码，显示名称选填；密码 8–128 个字符，支持粘贴和显示/隐藏，无确认密码或验证码步骤。提交时禁用重复操作，失败原位提示；网络错误保留输入并提供重试。退出后重新挂载页面，账户恢复的旧异步结果不能写回新账户状态。

学习功能就绪后，首页突出“开始学习”，提供默认课程资料，不先要求上传或创建知识库。选择章节是可选动作，学生可直接提问。没有作答时显示尚未评估，建议完成基础练习。

知识库首版为一个个人库加只读课程资料。多库管理按钮移入后续范围，减少首次设置。

## 3. 学习对话布局

```text
左侧主导航 / 会话列表 | 问题、回答、代码与学习操作 | 可展开引用侧栏
                     | 输入框、发送、取消         | 来源与原文定位
```

默认直接讲解；回答旁提供“给我提示”“用例子解释”，引导思考属于可选操作。无需进入设置页切换学习方式。

点击引用在当前页展开真实片段、章节或页码。点击“练习这个知识点”携带知识点与来源范围；练习结束可回到原会话。引用来源删除后提示状态，保留本人历史回答并隐藏未来原文读取入口。

生成中允许取消；失败保留输入并提供重试。切换页面不会隐式取消生成，回到页面读消息状态恢复；归档或新会话入口不强迫学生理解内部任务状态。

## 4. 知识库操作

上传前展示格式与大小限制。文档行仅展示“处理中 / 可用于学习 / 处理失败 / 已删除”，内部解析阶段可在详情中展开。

处理中可使用其他就绪资料；完成后提供“基于这份资料开始学习”，自动选中该文档。重复文件提示使用既有资料。重处理时该文档暂不可检索，显示状态并提供失败重试，其余文档正常可用。

删除确认展示文件名和影响：以后不再检索该资料，历史回答与练习仍保留。首版不实施文档历史版本管理或多库批量销毁操作。

## 5. 练习操作

配置区顶部直接提供“题库出题 / 实时 AI 出题”切换控件，首次默认题库，按当前用户记住上次选择。出题方式与“按章节 / 推荐练习”是两个独立选项。默认 5 题、基础难度，题量和难度放在“调整练习”中；来自对话的练习自动填充知识点。

题库模式从已核验题库选题，概念题是主要内容。AI 模式允许生成概念理解、算法过程、复杂度分析和综合应用等所有课程知识点的题目，提供可选“出题要求”输入框；不需要先选择算法模板或等待人工核验。无额外要求时点击“开始练习”即可。

切换保留知识点、题量和难度，AI 出题要求作为当前用户的配置草稿保留，在题库模式隐藏且不提交。切换仅用于下一组新练习；已开始练习保留题目、当前位置和作答，模式不会在作答中途改变。

学生选择答案，点击提示后由服务端记录提示使用；提交后同页显示结果、解析和引用。题目显示“题库题 / AI 生成”，AI 解析中的答案显示为参考答案。错误自动收录，下一题按钮仍在当前操作区，不强制跳往错题本。题库不足展示实际题量和原因，允许开始现有题目；AI 生成失败保留配置，提供“重试 / 切换题库”，不自动切换。

完成练习后显示本组结果、需要复习的知识点、回到原会话和查看错题入口。离开页面或刷新后恢复已提交答案和当前位置；未提交选择仅保存为页面草稿。

题目有问题时可提交反馈，维护者确认错误后停用并排除统计；学生反馈本身不直接撤销判分。

## 6. 错题、总结、报告和推荐

错题本默认显示待复习内容，选择题目后进入与普通练习一致的作答页面。保留原始错误、题库 / AI 来源和重做记录，复习按原题快照出题；正确一次不显示知识点已掌握。复习状态与知识点表现分别解释。

对话总结在当前会话内显示最新版本，标注截止消息，可导出 Markdown。无需摘要版本选择器。

报告默认最近 7 天，实时统计无需生成模型。只有用户点击“生成学习报告”时调用模型生成解释；等待时可继续学习，报告页可恢复状态。显示题量、首次独立作答正确率、提示作答与复习次数、有效样本数。

推荐直接嵌入首页、回答和报告，说明知识点匹配原因。点击在资料侧栏、资料页面或外部地址打开，不增加推荐管理模块。

## 7. 网页体验验收点

| 情况 | 预期反馈 |
| --- | --- |
| 没有个人资料 | 仍可开始课程学习 |
| 无作答 / 小样本 | 尚未评估 / 证据不足，不显示假掌握率 |
| 资料处理或模型失败 | 具体原因、原输入保留、重试入口 |
| 引用来源删除 | 来源状态可见，历史学习记录不突然消失 |
| 题目提交 | 原位反馈，不跳页，不重复计分 |
| 切换出题方式 | 保留知识点、题量和难度，新练习使用所选方式，历史结果不改变 |
| AI 生成失败 | 保留配置，可重试或主动切换题库，不自动换模式 |
| 刷新页面 | 会话及练习结果恢复 |
| 生成报告 | 与实时统计分开，标注生成时间和范围 |
| 前进与返回 | 保留会话、练习知识点、当前题目与阅读位置 |

桌面网页保留键盘操作、可见焦点、代码横向滚动和文档阅读区。引用侧栏可收起，为正文让出空间。不要把内部技术参数放入学生日常操作。

## 8. 现有原型的定位

上一轮可点击线框为 v0.1 示例，只验证模拟学习路径。它已有窄屏样式和历史浏览器检查记录，但本次不修改原型，不继续执行检查，也不把这些内容作为本版开发要求。

实际前端按本文件补齐默认个人库、资料带入会话、出题方式切换、题目草稿、练习结束返回等体验；本次审查结果不等于这些功能已实现。
