# 开发指南

当前为单机模块化单体：FastAPI、SQLite、Qdrant、Vue。启动和升级命令以仓库 README 为准；接口契约以运行中的 /docs 为准。

## 模块边界

- core：纯章节定义、输入结构、配置和模型端口。
- services：权限校验后的业务事务、文档处理、检索、AI 任务与当前响应。
- db：ORM 与数据库会话，生产写入使用 write_transaction。
- api：认证、请求校验和任务触发，公共分页类型来自 api/schemas.py。
- 前端 api：网络及类型；state：请求状态、草稿和账号隔离；views/components：展示与操作。

章节只在 core/chapters.py 定义。查询和校验由 services/chapters.py 处理，业务使用 chapter_id，不重新建立知识点树或主题标签。

学习对话页面使用服务端默认的合并资料范围和未归档会话列表。会话更新仅支持 title 与 archived，资料与章节在创建时确定；底层范围过滤仍用于隔离 RAG 评估及已保存回答的重试。

## 练习与事务

新练习只接受一个章节，由 AI 生成、复核后统一发布。整组作答在单个事务内预检全部答案、写入作答和错题；幂等重试不重复计分。提示、首次独立、重复和复习分类保留。

题目与分发快照有数据库不可变约束。确认有误的题目可由维护命令停用，不直接覆盖已分发内容。少于 5 道独立新题只显示证据不足。

不维护旧题库、多策略、逐题提交、反馈和历史格式适配。详见 [练习与章节](练习与章节说明.md)。

## 文档与检索

管理员维护课程资料，用户维护个人文件。课程上传必选章节，个人上传可选。文件就绪以实际解析、向量化及当前索引修订为准。

删除通过队列清理文件和向量，历史引用保持可解释；新检索和新练习重新检查当前权限与状态。来源许可与可读片段不得由模型编造。

批量导入须显式指定内容包，使用单个 chapter_code。隔离 RAG 评估使用测试目录中的语料，不导入日常课程库。

## 检查与迁移

执行 scripts/check.ps1：后端 Ruff/格式/测试/Alembic 差异，前端状态测试、类型检查和构建。测试使用临时数据库和模型替身；真实模型验收单独记录。

新增迁移不依赖会变化的应用常量，已有迁移不改写。0013 明确清空旧学习记录，保留账号和资料，删除旧分类及流程字段；升级前备份。不要在实际学习库上做测试降级。

SQLite 重建关联表仅在迁移连接暂时关闭外键，提交前验证完整关系并恢复。新建表或删除字段后执行 alembic check，不以迁移成功代替模型一致性检查。

## 当前架构结论

继续保持模块化单体，不引入通用仓储、微服务或额外章节管理层。清理优先依据真实入口与调用关系，避免为了历史测试保留已下线产品功能。详细检查见 [架构与清理检查](架构与清理检查.md)。
