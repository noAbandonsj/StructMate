课程初始化由维护者在 backend 目录执行：

```powershell
uv run --locked alembic upgrade head

```

初始化只更新固定课程库和目录，重复执行保留 ID、个人库和用户记录；不创建演示账号，不导入课程文档。目录共 8 个章节、23 个子知识点。模型不通过服务启动时的 create_all 建表。

时间字段在 SQLite 中保存 UTC，读取时恢复带 UTC 时区的 datetime，供后续会话到期判断使用。UTCDateTime 迁移渲染为标准 DateTime，避免迁移依赖后续可能变化的应用代码。方案参考 [SQLAlchemy UTC 时间处理](https://docs.sqlalchemy.org/en/20/core/custom_types.html#store-timezone-aware-timestamps-as-timezone-naive-utc)。
SQLite 连接启用明确事务控制，迁移使用事务式 DDL；外键和 WAL 配置在事务外设置，参考 [SQLAlchemy SQLite 事务与外键说明](https://docs.sqlalchemy.org/en/20/dialects/sqlite.html)。

## 已完成的简单账户（批次 B、C）

2026-10-12 已实现注册、登录、退出、当前账户、CSRF 读取和显示名称修改六个接口。注册将用户、默认“我的资料”库和会话一起提交，失败全部回滚，成功自动登录。

网页提供 /login、/register、登录恢复、学习页面路由保护及右上角账户菜单。用户名 3–32 位，密码 8–128 个字符，显示名称选填；失败在原位显示，网络错误保留输入并允许重试。注册或登录后返回原站内页面，退出后清除账户状态并重新挂载页面。

后端 api/auth.py 处理账户，core/auth.py 提供密码和 Cookie 会话辅助、AuthenticatedSession 依赖；后续受保护接口复用该依赖，并另行核对业务对象所有者。密码使用 pwdlib 的标准哈希；未加入 JWT、验证码、找回密码或请求限流。前端 state/auth.ts 仅使用小型共享状态，不保存登录凭据到 localStorage。

默认登录有效期为 7 天，CAPSTONE_SESSION_DAYS 可设为 1–30；正式环境 CAPSTONE_ENVIRONMENT=production 使用 Secure Cookie，需要 HTTPS。写请求使用配置来源或当前 API 同源的 Origin，登录后再携带账户响应中的 X-CSRF-Token。错误响应不回显密码或数据库参数。

## 资料管理与处理

0002 增加 documents、document_chunks、document_tasks。api/documents.py 提供保存、列表、配置限制、原文读取、片段、重处理与删除；private 对象统一检查本人归属，课程只读。uploads 使用内部随机路径标识，不采用客户端文件名拼接路径。

services/parsing.py 提取文本、段落与章节，记录 Markdown/TXT 的真实行位置及 PDF 页码；services/document_worker.py 为单进程内专用文档队列。模型与解析、向量操作均在数据库事务外，写入通过 write_transaction 的短 BEGIN IMMEDIATE 事务先获取 SQLite 写锁，避免已有读快照升级写锁时的并发冲突。

处理中资料暂不可检索；只有向量验证与 Qdrant 写入成功才设 ready。启动时中断的处理标为失败，不重放模型调用；queued 继续执行。删除先标 deleted，文件立即禁止读取，再清理文件和文档向量，最多重试三次；失败可手动重试，启动也恢复清理。已有片段与学习历史保留。

维护者课程导入执行 `uv run --locked python -X utf8 -m capstone.import_course`，原文件标准化为 UTF-8/LF 后核对摘要与许可；失败资料在接通服务后以 `--retry-failed` 重处理。文本文件预览统一返回 UTF-8 纯文本，下载保留原字节，不将 Markdown 作为任意 HTML 执行。

## 学习对话管线

0003 加入 conversations/messages；消息顺序和请求标识唯一，SQLite 部分唯一索引保证同会话最多一个生成回答。问题与回答同事务保存，相同标识内容冲突返回 409，未配置模型不创建伪回答或问题记录。最近失败/取消回答可创建新回答，原记录保留；服务启动只标记中断，不重放模型。

services/retrieval.py 按库权限、就绪状态和当前修订选资料，短事务外调用 Embedding 与 Qdrant，查询后再回查片段状态。索引配置与查询向量必须一致，来源来自实际命中片段，保留位置和正文快照。阈值 CAPSTONE_RETRIEVAL_MIN_SCORE 默认 0.25，尚未用真实模型校准。

services/chat_runner.py 只管理对话模型调用，最多同时处理两个会话，不引入通用任务平台。GenerationService 接收取消信号；具体适配必须限制网络超时并响应取消。所有输出持久化到消息快照，SSE 读取 snapshot/delta/citations/终态，不维护逐事件日志。每轮检查会话 Cookie，退出后关闭私有流。

网页 ChatView.vue 使用 EventSource，断线重连只恢复 GET 流；失败 POST 保留请求标识，防止响应丢失造成重复问题。草稿用 sessionStorage 按用户和会话隔离，不存凭据，退出时清理。引用使用 [资料1]，避免误改数组下标；文本由 Vue 转义展示。练习跳转与总结后续接入。

## 练习、判题与错题

0004 加入五表，业务共十四表。api/practice.py 使用同一套条目、提示与作答接口承载 bank/ai/review；服务端快照在提交前不下发答案。判题、提示分类、唯一计分、错题聚合和完成状态在短写事务保存。分发快照与已分发题目的关键字段由 SQLite 触发器保护。

维护者执行 capstone.manage_questions import 导入公开核验题，feedback 查看反馈，invalidate --id UUID --reason 原因 核验后停用。原题答案不被新源文件覆盖，历史保留。题库可独立于模型工作。AI 通过 GenerationService 返回 JSON，验证单选/判断结构、知识点与来源编号，不限制课程题型内容，不要求程序验算或人工审批。失败或重启中断保留设置，不自动回退或重放；完全相同的同用户 AI 题复用题目标识。

performance.py 按最近 30 天有效首次独立新题聚合章节：少于 5 道证据不足，足够后低于 60% 优先巩固。提示、重复与复习独立分类；题库与 AI 共同参与，停用题排除。错题连续正确日期使用 Asia/Shanghai，Windows 通过 tzdata 提供时区，跨日期与同日不重复计天已有测试。

PracticeView/WrongView 接入真实记录，练习来源偏好按账号保存在 localStorage，不保存凭据；自然语言要求和未提交选项仅放 sessionStorage，由 learning-drafts.ts 按账号隔离并在退出清理。会话与知识点跳转通过 URL 建议和服务端所有权检查保留上下文；AI 出题会收到原会话最近已完成消息。报告及总结还未接入。

## 数据与配置

根目录 .env 由后端加载，配置以 CAPSTONE_ 开头。
CAPSTONE_DATA_DIR 为相对路径时以仓库根目录解析；默认 SQLite 位于 data/capstone.db。
SQLite 开启外键、WAL 和 5 秒忙等待。Qdrant 本地目录仅由单个后端进程持有；服务关闭时释放客户端。

core/model_ports.py 定义 EmbeddingService 与批量向量校验；生产默认 UnconfiguredEmbedding，不产生模拟向量。连接参数已通过 Settings.connection 接入，具体 HTTP 适配仍未实现，调用协议已提问。首次成功写入创建 capstone_chunks 集合；后续校验维度和配置标识，不一致明确失败，不能自动清空已有索引。测试替身仅通过应用工厂的显式测试参数注入。
模型密钥后续仅通过后端配置注入，不放入 VITE_ 变量或页面代码。
当前 Vite 代理用于本地开发；构建后的网页可由同一后端进程提供，使用 -ServeWeb 或 CAPSTONE_SERVE_FRONTEND=true，具体见部署与使用说明。
