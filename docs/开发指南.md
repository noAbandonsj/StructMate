# 开发指南

当前工程使用规划 v0.3：桌面网页、模块化单体、SQLite + Qdrant 本地模式。

## 已完成的初始化

- Git 仓库使用 main 分支；开发变更通过本地提交记录，推送按明确要求执行。
- .gitignore 排除环境文件、私有学习数据、依赖、缓存和构建产物；示例配置与锁文件纳入版本管理范围。
- 后端：应用工厂、/api/v1/health、根目录环境配置、SQLite 会话基础、单实例 Qdrant、Alembic 框架。
- 前端：六个桌面页面入口、基础样式、404 页面、后端连接状态、/api 开发代理。
- uv.lock 与 pnpm-lock.yaml 固定实际依赖；启动脚本固定本地地址和端口。

## 添加后端功能

路由放在 backend/src/capstone/api/，注册时使用 /api/v1。
数据库模型继承 capstone.db.base.Base，在 migrations/env.py 中导入后生成迁移。
业务服务按实际功能加入对应模块，不提前创建空的平台层或所有业务表。
请求通过依赖获取短生命周期数据库会话；数据库事务外调用模型和向量接口。

```powershell
Push-Location backend
uv run --locked alembic revision --autogenerate -m "create account tables"
# 审查生成的迁移，再执行
uv run --locked alembic upgrade head
uv run --locked alembic check
Pop-Location
```

账户模块先实现用户、登录会话、默认个人库及必要课程基础，再逐步接入资料和学习功能。
不要运行旧 v0.1 schema.sql；不要用启动时 create_all 替代迁移。

## 添加网页功能

入口位于 frontend/src/router.ts；业务页面逐步替换 SectionView.vue 占位内容。
公共 API 调用放在 src/api/，使用相对 /api/v1 路径。
当前桌面布局不包含手机断点；真实登录之后再添加需要账户的路由保护。

题库 / 实时 AI 是出题来源，章节 / 推荐是练习策略，分别保存。
切换保留知识点、难度和题量；已开始练习保留原题快照。
AI 题无需程序验算或人工审批才能出题，按保存的参考答案反馈并保留来源。

## 数据与配置

根目录 .env 由后端加载，配置以 CAPSTONE_ 开头。
CAPSTONE_DATA_DIR 为相对路径时以仓库根目录解析；默认 SQLite 位于 data/capstone.db。
SQLite 开启外键、WAL 和 5 秒忙等待。Qdrant 本地目录仅由单个后端进程持有；服务关闭时释放客户端。

当前没有生成模型调用、Embedding 调用或向量集合，后续依据选定 Embedding 维度创建集合。
模型密钥后续仅通过后端配置注入，不放入 VITE_ 变量或页面代码。
当前 Vite 代理用于本地开发；生产静态部署与 /api 反向代理将在部署阶段配置。
