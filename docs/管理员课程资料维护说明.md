# 管理员与课程资料维护

更新：2026-10-17。对应 [规划](管理员课程资料维护规划.md)，沿用现有 Cookie 会话、CSRF、文件校验、后台文档处理与历史引用快照。

## 本机授权

先备份数据目录并在 `backend` 执行 `uv run --locked alembic upgrade head`。迁移 0009 将已有账号全部设为 `user`，增加角色取值约束和课程维护记录表，保留关联数据及原用户更新时间。

首次管理员由本机维护者指定。先通过网站注册普通账号，再在 `backend` 运行以下命令，将 `username` 换为真实已有用户名：

```powershell
uv run --locked python -X utf8 -m capstone.manage_admin list
uv run --locked python -X utf8 -m capstone.manage_admin list username
uv run --locked python -X utf8 -m capstone.manage_admin grant username
uv run --locked python -X utf8 -m capstone.manage_admin revoke username
```

命令不创建账号或修改密码，不存在的用户名会明确报错。网页没有角色修改入口，注册和显示名称接口拒绝额外的 `role` 字段。授权后刷新页面；撤销后原 Cookie 仍可用于普通学习，但下一次管理请求返回 `403 ADMIN_REQUIRED`，页面随请求恢复普通角色。

不在仓库中保存实际账号密码；项目不包含默认管理员。管理员也不能通过课程管理接口读取或修改任何个人库，个人接口仍只允许访问本人数据。

## 网页操作

1. 使用原登录页登录，侧栏出现“课程资料管理”，地址 `/admin/course`。普通用户直接访问此地址返回学习首页，管理 API 仍由服务端拒绝。
2. 默认先显示资料列表，包含名称、关联知识点、处理状态和更新时间；支持名称搜索、状态筛选和分页。“已删除”筛选可以查询历史删除记录；清理失败资料也保留在当前列表，便于刷新后继续重试。
3. 展开“上传课程资料”，选择文本型 PDF、TXT 或 Markdown。沿用服务端上传大小和内容校验，必须关联一个现有课程知识点，填写作者、来源和许可。勾选自编可自动填写来源和许可，仍允许修改。
4. 提交后仅表示文件已保存。等待实际状态变为“可用于学习”；未配置或无法调用向量服务时显示失败原因，文件仍可预览或下载。
5. 展开“解析片段与维护记录”，检查页码 / 行号与原文；维护记录显示本次网页上传、提交处理、删除及清理重试的操作者和时间。预置或历史导入资料没有网页记录时明确说明，不补造操作者。
6. 可重试的失败显示“重试处理”；不可重试的文件错误提示修正后重新上传。就绪资料可“重新处理”，排队后立即退出学习检索，完成后恢复；处理中不再提供重复处理按钮，服务端同时检查状态和请求幂等。
7. 更新内容采用“上传新版 → 等待就绪 → 核对 → 删除旧版”。删除确认明确说明影响所有学习者：未来不再检索该资料，后台清理原文件和向量；历史引用片段、对话、练习、错题、总结和报告快照保留。

删除成功、清理完成和清理失败分别反馈。清理失败可再次提交；不会把清理失败伪装成完全删除。管理页面不提供其他用户管理、教师班级、在线正文编辑或版本回滚。

## 导入命令

系统不再自带课程笔记和外部资源，管理员通过网页上传维护课程资料。迁移 0010 移除旧版预置内容，保留历史对话与引用，不删除管理员上传的文件和个人资料。

本机批量导入工具仍可用于管理员自己准备的内容包，但必须显式指定路径，不能无参数恢复旧版内容：

```powershell
uv run --locked python -X utf8 -m capstone.import_course --directory D:\CoursePacket
uv run --locked python -X utf8 -m capstone.import_course --directory D:\CoursePacket --retry-failed
```

内容包仍须包含 manifest.json、sources.json、资料文件及来源许可，并校验摘要。普通导入和失败重试不恢复已删除记录；需要恢复内容包内已删除资料时显式增加 `--restore-deleted`，建立新记录并保留历史。网页上传的文件通过网页重新上传。

## 管理 API

所有端点均要求当前用户为管理员，不依赖前端隐藏入口。写操作复用 Origin 与 CSRF 校验，实际写事务中再次检查角色与课程归属。

| 接口 | 用途 |
| --- | --- |
| `GET /api/v1/admin/course/documents` | 名称搜索、状态筛选、分页 |
| `POST /api/v1/admin/course/documents` | 文件及知识点、作者、来源、许可 multipart 上传；重复文件不覆盖来源 |
| `GET /api/v1/admin/course/documents/{id}` | 处理状态与结果 |
| `GET /api/v1/admin/course/documents/{id}/file` | 原文预览或 `download=true` 下载 |
| `GET /api/v1/admin/course/documents/{id}/chunks` | 当前就绪版本的解析片段、分页 |
| `GET /api/v1/admin/course/documents/{id}/history` | 网页维护操作者、操作与时间 |
| `POST /api/v1/admin/course/documents/{id}/process` | 请求标识幂等的失败重试或重新处理 |
| `DELETE /api/v1/admin/course/documents/{id}` | 逻辑移除及异步清理，清理失败时可重试 |

普通文档写接口仍拒绝课程写入，管理员需使用管理页面。管理员角色仅影响课程维护，不改变其他用户对象查询条件。

## 验收记录

自动化验证覆盖角色默认值与约束、旧账号迁移、注册和个人资料提权拒绝、本机授权及撤销、原会话即时失权、跨账号隔离、课程上传与来源、真实解析器 / Qdrant、重复文件、处理请求去重、失败重试、清理与历史引用、预置资料删除后的导入和显式恢复。

整体验证：`scripts/check.ps1` 通过 201 项后端测试、48 项前端状态测试、Ruff、迁移差异、TypeScript 与生产构建；随后新增的导入 / 删除竞争回归单独通过，后端共 202 项。前端覆盖管理端接口与来源字段、学生只读限制、撤销角色后的刷新，以及原学习流程的状态隔离。

内置浏览器使用正式管理员登录并上传自编队列资料，关联“队列”知识点，经真实向量服务达到就绪；可搜索、查看解析行号及 `admin` 上传记录。切换普通账号后管理入口消失，课程只读；使用该文件完成真实模型答疑，答案为甲、乙、丙，引用定位第 5 行。返回管理员进行重新处理，页面显示处理中并在完成前移除学习入口。浏览器检查删除确认；随后通过管理 API 清理本轮合成资料，确认后台完成、原文件返回 410，历史答案与引用片段保留且来源标记已删除。维护记录依次保留上传、处理和删除。普通账号请求管理 API 返回 403。

临时测试账号的管理员权限已撤销，保留用户指定的 `admin` 正式管理员；实际密码仅保存在本机数据库的哈希中。与升级前 SQLite 快照核对，原有 8 条消息、1 份学习报告和 4 份文档全部字段保持不变；新增测试会话保留用于核对历史引用，测试课程资料已清理。
