# DeepSeek 与千问模型接入

更新：2026-10-16。DeepSeek 流式生成与千问 Embedding 已完成真实调用和隔离业务闭环。实测模型为 deepseek-flash、qwen3.7-text-embedding-flash，向量为 1024 维。详见 [真实模型闭环验收记录](真实模型闭环验收记录.md)，其中区分初次发现与修复后回归。

## 填写本地配置

配置位于仓库根目录 .env，并被 Git 忽略；示例文件的密钥保持空白。当前本地密钥已由用户填写，本批次未改动 .env，也不展示密钥。新环境需自行填写以下两项并重启后端：

```dotenv
CAPSTONE_GENERATION_API_KEY=
CAPSTONE_EMBEDDING_API_KEY=
```

| 用途 | 当前示例 |
| --- | --- |
| 生成地址 | CAPSTONE_GENERATION_BASE_URL=https://api.deepseek.com |
| 生成模型 | CAPSTONE_GENERATION_MODEL=deepseek-flash |
| 生成超时 | CAPSTONE_GENERATION_TIMEOUT_SECONDS=60 |
| 向量地址 | CAPSTONE_EMBEDDING_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1 |
| 向量模型 | CAPSTONE_EMBEDDING_MODEL=qwen3.7-text-embedding-flash |
| 向量超时 | CAPSTONE_EMBEDDING_TIMEOUT_SECONDS=60 |
| 向量维度 | CAPSTONE_EMBEDDING_DIMENSION=1024 |

DeepSeek 的模型名称与请求格式按 [官方调用文档](https://api-docs.deepseek.com/) 核对；应用采用非思考模式，只发布最终正文，不发布 reasoning_content，单次输出上限 8192 tokens。接口地址支持 API 根路径或完整 chat/completions 路径，不重复拼接。

千问先提供北京区域兼容端点示例，见 [阿里云官方集成示例](https://help.aliyun.com/zh/hologres/user-guide/code-context-hologres)。**实际地址应与百炼控制台的地域、业务空间和密钥匹配**；当前 [Model Studio 文档](https://help.aliyun.com/zh/model-studio/text-embedding-synchronous-api) 也提供包含业务空间 ID 的地址，可直接替换 EMBEDDING_BASE_URL。1024 为本项目示例维度，不代表必须使用这个维度或这一地域。

地址和模型标识成组配置；API 密钥为空时，两种云服务保持不可用，不发送模型请求，也不把资料标记为就绪。填写密钥后重启后端，配置接口将报告已配置；这不代表服务连通或模型效果已验收。地址、模型、密钥均不下发网页。鉴权、频率、额度或服务错误只返回经过整理的原因，不回显响应原文和密钥。

## 调用与数据边界

core/model_http.py 实现两个端口，不引入多供应商管理平台或额外 SDK。HTTP 客户端为运行时依赖 httpx2；每次请求独立管理连接，禁止自动重试和跟随重定向。超时控制单次 HTTP 请求，默认 60 秒，可配置大于 0 至 600 秒。对话取消会关闭本次请求的连接，不影响其他请求；应用关闭后清理后台生成线程。

生成适配识别 SSE 保活、UTF-8 分片和用量事件，只发布正文。正常完成必须有 stop 和 DONE；断流、输出截断、无效事件或空正文均失败，不将部分结果当作完成。原有业务仍会保留失败或取消状态，用户主动重试才发新请求。

千问请求按最多 10 条拆分，按返回 index 恢复顺序，检查缺失、重复索引、有限数值、非零向量及批内/批间维度。配置了预期维度时，既把 dimensions 发给服务，也检查实际返回值；不一致明确失败。

真实 Flash 网关曾在批量返回中为所有行使用 index=0。适配仅针对此模型、行数正确且所有索引均为整数 0 的情形，丢弃整批歧义向量，再逐条发送原始文本，建立明确对应关系；不依据返回数组顺序猜测。单条仍校验索引、数值和维度，任一失败不发布部分结果。正常批量保持原方式；其他索引异常、鉴权和网络错误不会自动重试。该兼容路径会增加请求数和计费输入量。

向量指纹包含协议、实际接口、模型和实际维度，不包含密钥；正常换密钥不会要求重建。模型、接口或维度改变而与已有 Qdrant 集合不一致时，明确报错，不自动删除索引。真实库尚无新向量写入，本批次没有执行资料重处理。

## 填写密钥后的操作

1. 核对模型标识、千问地域/业务空间地址和维度，填写两项密钥并重启后端。
2. 管理员在“课程资料管理”页面上传课程文件或重试失败资料；个人文件可在“我的知识库”点击重试。真实向量写入成功才变为就绪。
3. 通过实际业务接口核对多轮答疑、引用、AI 出题、判题与错题、总结和文字报告。
4. 按 [RAG评估说明](RAG评估说明.md) 运行开发集与保留集，人工核对事实、来源支持和资料不足处理。

密钥留空时，账户、目录、文件原件、题库练习、错题、统计快照和维护资源推荐仍可使用。自动化协议测试与本地 HTTP 测试服务仅证明适配和管线行为，不替代以上真实模型验收。
