# 模型连接与接入状态

更新：2026-10-15。连接参数已实现并由后端读取；具体供应商、模型、调用协议及 HTTP 适配尚未确定。填写参数不会自动启用模型，不代表真实调用验收完成。

## 配置位置

配置位于仓库根目录 `.env`，字段见 [.env.example](../.env.example)。生成模型与 Embedding 分别使用一组配置，不在网页管理密钥，不建设多供应商平台。

| 用途 | 生成模型 | Embedding |
| --- | --- | --- |
| 接口地址 | CAPSTONE_GENERATION_BASE_URL | CAPSTONE_EMBEDDING_BASE_URL |
| 模型标识 | CAPSTONE_GENERATION_MODEL | CAPSTONE_EMBEDDING_MODEL |
| 可选密钥 | CAPSTONE_GENERATION_API_KEY | CAPSTONE_EMBEDDING_API_KEY |
| 超时秒数 | CAPSTONE_GENERATION_TIMEOUT_SECONDS | CAPSTONE_EMBEDDING_TIMEOUT_SECONDS |
| 预期向量维度 | 不适用 | CAPSTONE_EMBEDDING_DIMENSION，可选 |

地址和模型标识须同时填写；服务无需密钥时留空即可。整组留空表示未配置，空白行按空值处理。地址采用 HTTP(S)，认证凭据单独填写，片段标识不作为地址；合法查询参数可以保留，具体路径和参数语义由待确定的调用协议解释。超时默认 60 秒，允许大于 0 且不超过 600 秒；维度为正整数，留空表示以后由实际返回的向量确认。

后端启动时校验参数结构，配置不完整会明确失败。配置错误的文字诊断隐藏输入，密钥使用 SecretStr，默认配置序列化排除密钥。页面配置接口仅返回服务可用与否，不返回地址、模型标识或密钥。修改 `.env` 后需重新启动后端；本批次没有改动实际 `.env`。

## 当前可用范围

尚未接入调用适配时，账户、资料原文件管理、题库练习、错题复习、已有记录统计、统计快照及维护资源推荐可使用。依赖模型的答疑、AI 出题、总结和文字报告明确提示尚未接通；资料不会因填写连接参数就变为就绪。参数完整时，内部未接通服务还会说明调用协议适配尚未接通。

core/model_config.py 定义不可变连接参数；Settings.connection 分别读取两组连接；应用工厂把连接传给模型端口。测试替身仅通过显式工厂参数注入，生产没有模拟成功分支。

## 接通后的核验要求

确认服务与协议后，为现有 GenerationService.stream 和 EmbeddingService.embed 实现具体调用。处理鉴权、超时、取消、流式结束和错误时，不向前端或日志回显密钥和服务响应原文。使用配置中的预期维度检查实际向量，并把实际模型配置标识与维度绑定到现有向量集合；不一致要明确失败，不清空用户索引。

现有 EmbeddingBatch 与向量存储已经检查向量数量、有限数值、非零向量、批内维度及集合维度。新增的预期维度字段需要由后续具体调用适配执行，当前尚不能据此声称完成真实 Embedding 验收。

真实验收仍需：课程文件真实向量化、带原文引用的多轮对话、AI 出题及提交、自动错题和复习、实际总结和文字报告，以及固定评估集的人工核对。自动化测试替身的结果只证明管线行为。
