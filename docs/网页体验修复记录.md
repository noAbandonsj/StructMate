# 桌面网页体验修复记录

日期：2026-10-16。保留米白与绿色视觉体系，优化现有学习流程，不新增移动端、主题管理或考试系统。

## 已完成

| 问题 | 当前行为 |
| --- | --- |
| 顶部连接状态只在首次加载检查 | 可见页面每 30 秒检查，窗口重新获得焦点、网络恢复时复查；业务请求网络错误或 5xx 及时标为异常。取消请求和输入校验错误不误报断线，旧健康响应不能覆盖更新的失败 |
| 加载失败被显示为没有历史 | 练习与报告分别显示加载中、读取失败和确实无记录；失败保留已加载数据及局部重试，练习设置未就绪时阻止创建 |
| 难度与题量藏在折叠项 | 出题方式与难度使用常驻单选按钮，统一基础/进阶/挑战；显示难度侧重点，提供 5/10/20 题及 1–20 自定义题量 |
| 知识点列表依赖 Ctrl 多选 | 按章节分组勾选、搜索、已选计数，清空后明确采用全部知识点；额外 AI 要求与推荐依据按需展开 |
| 生成等待含义不清 | 说明正在生成并复核，可离开后恢复；当前题组生成期间禁止从该页面重复创建，不展示虚构进度 |
| 控件样式混杂、详情导航失去高亮 | 统一按钮、下拉框、输入框及键盘焦点；详情路由保持所属模块高亮；历史日期单独换行 |
| 练习需要反复滚动找题 | 增加题号导航、已答状态、下一道未作答题、提交后的正确/错误选项与结果样式 |
| 桌面窗口缩窄时主页面溢出 | 调整侧栏、内边距及网格最小宽度；窄桌面引用侧栏改为固定抽屉，支持 Escape 关闭与焦点返回，不增加手机布局 |
| Markdown 按原始文本显示 | 回答、总结、报告与解析使用公共阅读组件，支持标题、列表、表格、行内代码、代码块复制；用户原始输入保留纯文本 |
| 日期范围操作繁琐 | 增加上海日期的近 7/30 天快捷选择；自定义日期修改后要求先更新统计；空日期边界按服务端实际范围补齐，不覆盖请求期间新输入 |
| 报告首屏信息过多 | 保留四项核心指标，将作答明细折叠；实时统计与历史快照仍分开呈现，不改写历史报告 |

阅读组件采用 markdown-it 解析和 Vue 节点白名单渲染，没有使用 v-html。原始 HTML、事件属性、样式及自动图片加载不进入页面；只允许安全的网页/本站链接。已知资料编号仅在普通正文中变为按钮，代码、链接内部及未知编号保持文本。参考 [markdown-it 安全说明](https://github.com/markdown-it/markdown-it/blob/master/docs/safety.md)。
