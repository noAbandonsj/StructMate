# 栈与队列：操作过程与循环队列

所属章节：栈与队列。适用程度：入门至基础应用。

## 1. 栈与队列的基本区别

栈和队列都是操作受到限制的线性表。栈只允许在同一端插入和删除，该端叫栈顶；栈遵循后进先出（LIFO）。队列在队尾插入、在队头删除，遵循先进先出（FIFO）。栈常用于括号匹配和函数调用管理，队列常用于任务排队和二叉树层序遍历。

本材料描述栈内容时，统一从左到右表示“栈底到栈顶”；描述队列内容时，统一从左到右表示“队头到队尾”。表示方向属于例题条件，不能自行反转。

## 2. 顺序栈的 top 约定

本材料使用容量为 capacity 的数组 s 存栈，top 指向当前栈顶元素下标。空栈 top=-1；满栈 top=capacity-1。入栈时先检查是否已满，再执行 top=top+1 和 s[top]=x；出栈时先检查是否为空，再读取 s[top]，最后执行 top=top-1。非空时元素个数为 top+1。

另一些教材令 top 指向下一个可写槽位，空栈 top=0。这是另一种合法约定，但它的判空、判满和入栈顺序必须成套使用，不能把两种 top 含义混在同一题中。

容量足够且不触发扩容时，顺序栈的入栈、出栈、读取栈顶均为 O(1)。读取栈顶不会删除元素，出栈会改变栈状态。空栈出栈称为下溢；定长栈已满后继续入栈应报告溢出。

## 3. 栈操作实例：书签恢复记录

某阅读器用空栈保存书签编号，依次执行：push(17)、push(28)、pop()、push(46)、push(59)、pop()。执行后的状态依次为 [17]、[17,28]、[17]、[17,46]、[17,46,59]、[17,46]。两次出栈返回值依次为 28 和 59；最终栈顶为 46，top=1，栈中有 2 个元素。

对于按顺序入栈的 1、2、3，允许入栈与出栈交错进行，但每次只能弹出栈顶。出栈序列 2、1、3 可以实现：入 1、入 2、出 2、出 1、入 3、出 3。出栈序列 3、1、2 无法实现，因为先弹出 3 后，2 位于 1 上方，无法绕过 2 直接弹出 1。

## 4. 用栈检查括号匹配

从左到右扫描字符串，只处理圆括号、方括号和花括号。遇到左括号就压栈；遇到右括号时，如果栈空则匹配失败，否则弹出一个左括号，检查类型是否对应。扫描结束后栈也必须为空。忽略其他字符时，该算法可用于含普通字符的表达式。

字符串 {[()]} 的左括号依次入栈 {、[、(，随后右括号依次匹配 )、]、}，最后栈空，匹配成功。字符串 ([)] 虽然左右括号总数相同，但读到 ) 时栈顶是 [，类型不匹配，立即失败。字符串 (() 在扫描结束后仍残留一个左括号，也应失败。

扫描长度为 n 的字符串，每个字符最多触发常数次栈操作，因此时间复杂度为 O(n)，最坏辅助空间为 O(n)。若输入是空字符串，按本算法的通常定义，其括号匹配成立。

## 5. 循环队列：预留一个空位的约定

设循环队列数组长度为 m，且 m≥2，合法下标为 0 至 m-1。本材料约定 front 指向队头元素，rear 指向下一次入队的写入位置，采用“预留一个空位”的方法区分空与满。初始化 front=rear=0。以下公式只适用于本节约定。

- 判空：front == rear。
- 判满：(rear+1) % m == front。
- 元素个数：(rear-front+m) % m。
- 最大可存元素数：m-1，而不是 m。

入队前检查是否已满；未满则执行 q[rear]=x，再令 rear=(rear+1)%m。出队前检查是否为空；非空则读取 q[front]，再令 front=(front+1)%m。每次操作为 O(1)。取模使下标越过数组末尾后回到 0，从而复用队头已经释放的位置。

当 front 与 rear 相等时，预留空位方案把该状态定义为空，因此不能再允许存满 m 个元素，否则满状态也会出现两者相等。如果采用额外计数器或标志位，可以使用全部 m 个槽位，但此时判满公式必须相应调整。

## 6. 循环队列实例：云杉打印站

云杉打印站的循环队列数组长度 m=6，初始 front=rear=0。依次入队 11、22、33、44 后，front=0、rear=4，逻辑队列为 [11,22,33,44]。连续两次出队，返回 11、22，front=2、rear=4，逻辑队列为 [33,44]。

接着依次入队 55、66、77：55 写入下标 4 后 rear=5；66 写入下标 5 后 rear=0；77 写入下标 0 后 rear=1。最终 front=2、rear=1，逻辑队列为 [33,44,55,66,77]。元素个数为 (1-2+6)%6=5，且 (1+1)%6=2 等于 front，因此队列已满。此时继续入队 88 应失败，front 和 rear 均保持不变。

本例物理下标 1 是预留的空位，数组其他已出队槽位可能保留旧值；判断队列内容应从 front 开始按循环次序读取有效元素，不能直接把整个数组从下标 0 打印到 5 当作逻辑顺序。

## 7. 顺序队列的“假溢出”与结构选择

若普通顺序队列只让 rear 向高下标移动，当 rear 到达数组末尾时，即使前面因出队留下空位，也可能无法继续入队，这称为假溢出。循环队列通过取模复用空位，不必为了每次出队移动全部元素。

需要按到达顺序处理任务时适合队列；需要优先处理最近保存的状态时适合栈。把同样的输入 7、8、9 全部存入后再全部取出，栈的取出顺序为 9、8、7，队列为 7、8、9。该结论假定中间没有其他交错操作。
