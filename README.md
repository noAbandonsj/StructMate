# 知序 · 数据结构课程学习助手

基于 RAG 的桌面网页项目，后端使用 Python / FastAPI，前端使用 Vue 3、TypeScript 和 Vite。
业务数据保存到 SQLite，文档向量使用 Qdrant 本地持久化模式。

目前完成基础工程初始化：网页导航、服务连接状态、后端健康接口、本地存储连接、迁移框架、开发脚本与依赖锁文件。
账户与知识库的数据基础已完成：四张业务表、首个迁移和课程目录初始化。
注册、登录、退出、刷新恢复登录、显示名称修改及桌面账户页面已实现，注册时自动创建个人知识库。
知识库列表、详情和课程目录页面已接入真实数据，并检查个人库访问权限。
资料上传、预览、下载、删除、失败重试和文档处理管线已接入网页；学习对话的保存、真实检索管线与流式页面已实现，题库练习、AI 出题管线、判题与错题复习已实现，会话总结与 Markdown 导出已接入，报告页统计、历史快照与导出已接入，资料推荐已接入首页、会话和报告页。已接入 DeepSeek 流式生成与千问 Embedding 的 HTTP 适配；按要求密钥暂留空，真实模型验收待完成，未配置时资料不会标为就绪。
首批公开内容已整理为 3 份中文笔记、15 道固定题和 30 个评估问题，来源与许可见 [内容说明](content/README.md)。维护者可用导入命令将笔记登记为课程资料；向量就绪须接入真实 Embedding，15 道核验题可直接用于练习，AI 出题仍需接通真实生成服务。

学习报告默认显示最近 7 个上海日期的服务端真实记录，可调整日期。实时统计与历史快照分开；保存时固定日期、截止时间和口径，后续作答或停用题目不改写旧报告。未配置生成模型时仍能保存和导出统计快照，明确显示文字未生成。首页提供最近会话与练习入口。

资料推荐按所选知识点所在章节、有效待复习题和优先难度排序。同章不同难度与难度未评定会明确标注；没有足够候选时不补造资源。本人可访问的就绪资料可原位阅读当前片段和查看原文件；外链均为维护者登记，普通页面不联网生成链接。默认提供 6 条英文资源，包含作者与许可。维护者更新 content/resources.json 后运行 capstone.manage_resources，可重复导入；设置 is_active=false 后导入即可停用，不增设管理页面。

真实模型接通后的固定问题评估命令见 [RAG 评估说明](docs/RAG评估说明.md)，完整待验收项见 [初版验收清单](docs/初版验收清单.md)。当前未配置状态会明确停止评估，不生成模型实测文件。

## 环境

模型连接参数与当前接入边界见 [模型接入说明](docs/模型接入说明.md)。后端已支持 DeepSeek 与千问的地址、模型标识、密钥和超时。非敏感默认值已准备；填写两项 API 密钥并重启后端才能发起模型请求，密钥为空时仍明确未配置。

- Python 3.13（本次验证版本 3.13.7；工程声明兼容 3.12–3.13）。
- Node.js 22.12+（本次验证版本 24.11.1）。

## 安装与启动

在仓库根目录的 PowerShell 中执行：

```powershell
if (-not (Test-Path -LiteralPath .env)) { Copy-Item .env.example .env }

Push-Location backend
uv sync --locked
uv run --locked alembic upgrade head
uv run --locked python -X utf8 -m capstone.seed
uv run --locked python -X utf8 -m capstone.import_course
uv run --locked python -X utf8 -m capstone.manage_questions import
uv run --locked python -X utf8 -m capstone.manage_resources
Pop-Location

Push-Location frontend
pnpm.cmd install --frozen-lockfile
Pop-Location
```

已有 .env 时保留原文件并按 [.env.example](.env.example) 补充配置。本轮初始化已在本机安装依赖，无须配置模型密钥。
当前迁移 0001 创建四张账户与目录表，0002 加入文档、片段及文档任务，0003 加入会话和消息，0004 加入题目、练习、条目、作答和错题，共十四张业务表，0005 在会话内加入最新总结字段，0006 加入学习报告，0007 加入维护资源，共十六张业务表。
课程初始化可重复执行，写入一个课程库和 31 个目录节点（8 个章节、23 个子知识点），保留已有 ID 和个人数据；不创建演示账号或课程文档。
它不会自动执行迁移，数据库未升级时会提示先执行 upgrade head。-X utf8 保证初始化命令输出中文时使用 UTF-8。

分别在两个终端中运行：

```powershell
# 终端 1：后端
.\scripts\start-backend.ps1

# 终端 2：网页
.\scripts\start-frontend.ps1
```

网页地址：`http://127.0.0.1:5173`；接口文档：`http://127.0.0.1:8000/docs`；
健康接口：`http://127.0.0.1:8000/api/v1/health`。网页 /api 通过 Vite 代理到后端。

后端开发可使用 `.\scripts\start-backend.ps1 -Reload`。终端中按 Ctrl+C 停止各自服务。
构建版本可先在 frontend 执行 `pnpm.cmd build`，再运行 `.\scripts\start-backend.ps1 -ServeWeb`，直接访问 `http://127.0.0.1:8000`，无需启动 Vite。网页刷新与 API 均由同一个后端处理；完整安装、操作及备份说明见 [部署与使用说明](docs/部署与使用说明.md)。
若 PowerShell 执行策略阻止本地脚本，可在当前调用使用
`powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-backend.ps1`，其他脚本同理。

## 账户操作

1. 启动后打开网页，未登录会进入登录页；首次使用点击“创建账号”。
2. 输入用户名和密码，显示名称选填。用户名 3–32 位英文字母、数字或下划线，密码 8–128 个字符。
3. 注册成功直接进入首页，并自动创建“我的资料”；已有账号直接登录。刷新网页会恢复未过期的登录。
4. 右上角账户菜单可修改显示名称或退出。退出回到登录页，个人资料仍保留。
5. “我的知识库”显示本人个人库与只读课程库，点击卡片查看基础信息；下方可搜索、展开八章课程目录。个人库可保存资料、查看状态、预览、下载、重试及删除；课程库提供只读资料及来源许可。

账户实现保持简单，密码用 pwdlib 保存标准哈希；登录通过服务端会话 Cookie 保持，默认 7 天，不要求邮箱或验证码。
CAPSTONE_SESSION_DAYS 可设置为 1–30 天；已有 .env 未添加该配置时使用默认值。

## 资料操作与当前限制

在“我的知识库”选择个人库，上传文本型 PDF、TXT 或 Markdown，默认最多 20 MiB。文件保存后可预览或下载；文本支持 UTF-8、GB18030，扫描与加密 PDF 暂不支持。处理完成前不参与学习检索。页面保留失败原因与重试入口，删除前确认，删除后文件不可读取并后台清理。历史学习记录保留。

课程导入命令可重复执行，校验文件摘要、知识点和许可，仅登记资料，不伪造向量。后台启动后执行队列；未接通 Embedding 时文件保留并显示处理失败。DeepSeek 与千问兼容接口已实现，可通过后端环境配置接入；本地密钥按要求留空，尚未请求真实模型。接通真实服务后，维护者可执行 `uv run --locked python -X utf8 -m capstone.import_course --retry-failed` 重试课程资料；学生在个人库点击重试。

## 学习对话

首页点击“开始学习”，在会话列表新建学习，默认使用课程＋我的资料，可选择仅课程或仅个人。就绪资料列表的“学习这份资料”携带文档与知识点建立限定范围会话。会话设置可改名、调整范围、归档和恢复。

接通模型后可提问或连续追问，选择直接讲解、提示或例子；回答中的 `[资料1]` 可在当前页打开实际检索片段、页码或行位置。数组 `a[0]` 不作为引用。删除资料后显示历史片段和来源已删除，原文件入口关闭；没有命中依据时明确资料不足。

可取消正在生成的回答，重试最近失败或取消的问题；刷新恢复会话及正在生成的流，断线时“重新连接”不重复提交。草稿按账号和会话保存在当前浏览器会话中，退出清理；服务端只保存已发送问题。会话可分页，长记录支持查看更早消息。可从会话或引用进入知识点练习，并从练习返回原会话；会话下方可按需总结完整问答，显示截止时间和范围；新回答不会混入已开始生成的总结，旧总结仍可在失败时查看和导出。

当前 HTTP 适配已就绪，本地尚未填写密钥：创建会话和查看历史可用，提问明确提示服务未配置并保留输入，不生成演示回答。检索和流式测试使用显式模型替身及真实 Qdrant，不代表模型效果验收。实现参照 [Qdrant 过滤](https://qdrant.tech/documentation/search/filtering/) 和 [FastAPI 流式响应](https://fastapi.tiangolo.com/advanced/stream-data/)。

## 练习与错题

进入练习中心，首次默认题库，默认 5 题、基础难度。可切换实时 AI、选择知识点、题量及难度，AI 支持自然语言要求。更改只影响下一组，保留已有题目。题库数量不足说明实际题量；失败保留原设置，可按原设置重试或主动切换，不自动改出题方式。未配置模型也能使用题库。

选择选项后逐题提交，原位显示答案、解析与来源，错误自动进入错题本；作答前接口不下发答案。使用提示由服务器记录，重复提交只保存一次。错题页支持按知识点或状态筛选、单题或所选成组复习及历次作答；不同上海日期连续两次答对标记该题已巩固，再次答错回到待复习。

推荐练习依据最近 30 天不同新题首次独立作答：少于 5 道显示证据不足，样本足够且正确率低于 60% 时优先巩固。题库与 AI 题均参与，AI 按保存的参考答案计分；提示、重复与复习不增加独立新题样本。同用户重复生成完全相同的 AI 题复用原题，不反复算新题。

网页记住当前账号的出题设置；未提交选项与出题要求是当前浏览器会话草稿，不计分，退出时清除。刷新从服务器恢复已开始练习与已提交结果，AI 题生成中状态会轮询；服务器重启后中断生成标为失败，不自动重放模型调用。

提交后可反馈题目问题。维护者在 backend 执行 `uv run --locked python -X utf8 -m capstone.manage_questions feedback` 查看反馈，核验后以 `uv run --locked python -X utf8 -m capstone.manage_questions invalidate --id <题目UUID> --reason "确认的原因"` 停用并排除当前统计；历史快照与作答保留。题库内容修改后重新导入会创建新题，分发快照不被覆盖。

## 检查

```powershell
.\scripts\check.ps1
```

包含后端 Ruff 检查与格式检查、接口及存储测试、迁移差异检查，以及网页状态测试、TypeScript 检查与生产构建。
测试使用临时数据目录，验证 SQLite 配置、Qdrant 重启持久化和锁释放、存储故障的健康状态。
同时验证十四表迁移、关键约束、事务回滚、UTC 时间和课程初始化；测试不会降级或清空实际运行数据库。
账户测试覆盖自动建库、重复用户名、错误密码、注册失败回滚、会话过期与退出、来源及请求凭据校验。
知识库测试覆盖双账号隔离、课程库只读信息、目录与分页；网页状态测试验证换账号、快速切库、登录失效及网络错误。网页状态测试使用 Node，不启动浏览器。
文档测试使用真实文件、解析器和 Qdrant，Embedding 测试替身仅用于测试；覆盖重复文件、重启恢复、处理失败、清理重试、课程导入和私人资料隔离，不等同于真实模型验收。
本阶段不运行浏览器自动检查，也不开发手机端适配。
